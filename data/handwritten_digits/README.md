# El Yazısı Görselleri (Şablon)

Bu klasöre kendi el yazınızla yazdığınız rakam/öğrenci numarası görsellerini koyun.

Öneri:
- Gri tonlamalı kayıt edin.
- Arka planı açık, rakamı koyu olacak şekilde hazırlayın.
- Büyük görseller kabul edilir; kod otomatik 28x28'e ölçekler.

Örnek kullanım:

```bash
python -m mnist_mlp.handwriting --checkpoint outputs/run/checkpoint.pt data/handwritten_digits/0.png data/handwritten_digits/1.png
```
